==============================================================================
格式        位域           偏置    有效位        最小正规数        最大正规数      数量级跨度
------------------------------------------------------------------------------
fp64      1+11+52    1023     53  2.2251e-308  1.7977e+308    615.91x
fp32      1+8+23      127     24   1.1755e-38   3.4028e+38     76.46x
tf32      1+8+10      127     11   1.1755e-38   3.4012e+38     76.46x
bf16      1+8+7       127      8   1.1755e-38   3.3895e+38     76.46x

fp8_e4m3  1+4+3         7      4     0.015625          240      4.19x  注：本脚本是通用 IEEE 模型（全1指数留给 inf/NaN），真实 E4M3 无 inf、最大 448
fp8_e5m2  1+5+2        15      3   6.1035e-05        57344      8.97x

--- 同一个数 1.5 在各格式里的位模式与往返误差 ---
fp64       0 01111111111 1000000000000000000000000000000000000000000000000000  ->  1.5   误差 0.000e+00
fp32       0 01111111 10000000000000000000000  ->  1.5   误差 0.000e+00
tf32       0 01111111 1000000000  ->  1.5   误差 0.000e+00
bf16       0 01111111 1000000  ->  1.5   误差 0.000e+00
fp16       0 01111 1000000000  ->  1.5   误差 0.000e+00
fp8_e4m3   0 0111 100  ->  1.5   误差 0.000e+00
fp8_e5m2   0 01111 10  ->  1.5   误差 0.000e+00

--- 关键门槛（fp16）：解码公式逐项核对 ---
  最小正规数        = 2^(1-15)        = 2^-14       = 6.1035e-05
  subnormal 间距    = 2^(1-15-10)   = 2^-24       = 5.9605e-08
  subnormal 个数    = 2^10-1          = 1023
  最大正规数        = 2^-14 * (2-2^-10)  = 65504
  溢出阈值          = 65504；超过 -> inf，实测 65520 -> inf

==============================================================================
【2】subnormal：指数用光了，借尾数位继续往下表示
==============================================================================
--- 边界：位模式只差最后一位，值却跨过 2^-14 ---
  最小正规数     0 00001 0000000000  -> 6.1035e-05
  最大 subnormal 0 00000 1111111111  -> 6.0976e-05
  最大 subnormal + ulp == 最小正规数 ? True
  -> 间距固定 = 5.9605e-08 = 2^-24，无缝衔接（gradual underflow）

--- 采样：subnormal 区里 exp 字段恒为 0 ---
    1.5259e-05 -> 0 00000 0100000000  (exp=00000 => subnormal)
    9.5367e-07 -> 0 00000 0000010000  (exp=00000 => subnormal)
    5.9605e-08 -> 0 00000 0000000001  (exp=00000 => subnormal)

--- subnormal 的代价：有效位数线性退化（值 = M * 2^-24）---
       M      需要的位数              值       相对精度
    1023         10     6.0976e-05        10bit
     512         10     3.0518e-05        10bit
     256          9     1.5259e-05         9bit
     128          8     7.6294e-06         8bit
      64          7     3.8147e-06         7bit
      32          6     1.9073e-06         6bit
      16          5     9.5367e-07         5bit
       8          4     4.7684e-07         4bit
       4          3     2.3842e-07         3bit
       2          2     1.1921e-07         2bit
       1          1     5.9605e-08         1bit
  -> 指数不能再减了，只好牺牲尾数位：这叫用精度换连续性

--- 三种格式都有 subnormal 机制（个数 = 2^尾数位 - 1）---
  格式          偏置     尾数位          最小正规数     subnormal 间距   subnormal 个数
  fp32       127      23     1.1755e-38       1.4013e-45        8388607
  bf16       127       7     1.1755e-38       9.1835e-41            127
  fp16        15      10     6.1035e-05       5.9605e-08           1023

--- FTZ 风险：不支持 subnormal 的硬件会把它们刷成 0 ---
  输入 1e-05  IEEE(有subnormal) ->   1.0014e-05    FTZ(刷0) ->            0
  输入 1e-07  IEEE(有subnormal) ->   1.1921e-07    FTZ(刷0) ->            0
  输入 1e-08  IEEE(有subnormal) ->            0    FTZ(刷0) ->            0
  -> 1e-7 在 IEEE 下是一个 subnormal，还能用；在 FTZ 硬件上直接变 0
  -> 量化 scale 一旦归零，整层输出全废：这是模拟器与板子不一致的经典来源

==============================================================================
【3】量化 scale 的表示域困境 —— 私有格式 fp16s/fp16e 的由来
==============================================================================
scale = max|w| / 127，权重越大 scale 越大；小模型的 scale 会很小。

--- 标准 fp16（bias 固定 15）：scale 越小，有效位掉得越狠 ---
     max|w|        scale      理想指数          落点           实存值       相对误差     有效位
      1e-01   7.8740e-04         4         正规数  7.872581e-04      0.02%     11bit
      1e-02   7.8740e-05         1         正规数  7.873774e-05      0.00%     11bit
      1e-03   7.8740e-06        -2   subnormal  7.867813e-06      0.08%      8bit
      1e-04   7.8740e-07        -6   subnormal  7.748604e-07      1.59%      4bit
      1e-05   7.8740e-08        -9   subnormal  5.960464e-08     24.30%      1bit
      1e-06   7.8740e-09       -12   subnormal  0.000000e+00    100.00%      1bit

--- 私有格式 fp16e：把偏置 e0 变成可配参数（re-bias / 滑动窗口）---
    原理一句话：e0 把该张量的量级搬到 1 附近，窗口就跟着张量走。
    目标 scale = 1.0000e-06，其二进制量级 = 2^-20

     e0   scale 的 E    合法?          窗口下界         窗口上界     有效位
     15          -5      ✗    6.1035e-05        65504       —
     23           3      ✓    2.3842e-07      255.875   11bit
     31          11      ✓    9.3132e-10     0.999512   11bit   <- 本文前面用的值
     35          15      ✓    5.8208e-11    0.0624695   11bit   <- 量级归一化到这里（E=15）
     45          25      ✓    5.6843e-14   6.1005e-05   11bit

    注意：窗口宽度永远是 2^30 ≈ 9.03 个数量级（指数位固定 5 位），
         e0 只决定这个窗口摆在哪一段实数轴上。

--- 同一个 16 位容器，只改偏置，精度差多少 ---
  fp16  (e0=15) : 1.013279e-06   相对误差   1.33%
  fp16e (e0=35) : 1.000240e-06   相对误差   0.02%
  精度提升约 5.8 bit —— 这就是 fp16s / fp16e 存在的理由

  ⚠️ 前提：re-bias 只能把 subnormal 升级成正规数，
     对本来就在正规区的张量，一点精度都不多给。

【4】为什么芯片需要更宽的内部容器（fpin 33bit 的动机）
==============================================================================
--- 4.1 吸收阈值：1.0 上面加一个微小量，能不能改变结果 ---
    （ulp 是'1.0 处的最小可分辨增量'；比半个 ulp 还小的加数会被直接丢掉）
     阶       加数 2^-p    fp16 生效?         加宽容器(25bit) 生效?
     9    0.00195312        True                    True
    10   0.000976562        True                    True   <- fp16 的阈值
    11   0.000488281       False                    True
    12   0.000244141       False                    True
    13    0.00012207       False                    True
    14    6.1035e-05       False                    True
    15    3.0518e-05       False                    True
    16    1.5259e-05       False                    True
    17    7.6294e-06       False                    True
    18    3.8147e-06       False                    True
    19    1.9073e-06       False                    True
    20    9.5367e-07       False                    True
    21    4.7684e-07       False                    True
    22    2.3842e-07       False                    True
    23    1.1921e-07       False                    True
    24    5.9605e-08       False                    True   <- 加宽容器的阈值
    25    2.9802e-08       False                   False
    26    1.4901e-08       False                   False
    27    7.4506e-09       False                   False
  -> fp16 要求加数 >= 2^-10；加宽容器要求 >= 2^-24
  -> 抗吸收余量放大 2^14 = 16384 倍
  -> 等价说法：1.0 处的最小可分辨增量从 fp16 的 2^-10 压到容器内的 2^-24

--- 4.2 长累加：加 K 个 1.0，看结果对不对 ---
         K        fp16 顺序加       加宽容器(25bit)         精确值     fp16 误差
      1000            1000              1000        1000       0.00%
     10000            2048             10000       10000      79.52%
     70000            2048             70000       70000      97.07%
  -> fp16 在 2048 附近就停住了：再加 1.0 只是半个 ulp，被 round-half-even 丢掉
  -> 这不是溢出（fp16 上限 65504），而是**吸收**：大数与小数相加，小数消失了

--- 4.3 与精确值对比：更真实的点积（K 项，量级跨 6 个数量级）---
       K       fp16 累加偏差          加宽容器偏差        改善倍数
      64      1.225e-04       2.399e-08     5104.8x
     256      2.676e-03       6.555e-08    40828.8x
    1024      2.417e-04       1.081e-07     2237.2x
    4096      1.348e-02       3.917e-08   344195.0x

  注：加宽容器仍非零误差——指数差超过 25 位时一样会舍入，
     只是阈值抬高、且'每步都舍'变成'少数几步才舍'。
