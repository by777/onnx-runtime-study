# 激活函数查表适用性 —— 判断清单

> 从 softmax 的 exp 推广到"任意激活函数"：理论上任何单值函数都能查表，
> 但**值不值得、好不好查**取决于函数性质。本文给一张判断清单 + 逐函数结论。

---

## 一、核心判据（来自 step5 的误差公式）

线性插值误差上界：

$$\varepsilon \le \frac{h^{2}}{8}\max|f''(x)|,\qquad h=\text{段宽}=\frac{\text{输入区间}}{\text{段数}}$$

它告诉我们三个事实：

1. **误差由"曲率 f''"决定，不是"斜率 f' "决定**（一阶项被线性插值抵消了）
2. **误差 ∝ 段宽 h²**，而 h = 输入区间 / 段数 → 输入区间越大越难查
3. 因此真正要看的两个量：**输入区间**（决定 h）和 **二阶导 f''**（决定曲率）

> ⚠️ 最反直觉的一点：**陡但直的函数查表零误差，缓但弯的函数误差最大**。
> 难查的是"弯得急"（曲率大），不是"斜得陡"。

---

## 二、三个限制

| 限制 | 含义 | 决定 |
|---|---|---|
| ① 输入区间 | 表要覆盖整个输入范围 | 需不需要 range reduction |
| ② 曲率 f'' | 曲率大的地方直线掰不过弯 | 段要密不密、要不要非均匀分段 |
| ③ 单值性 | 一个输入只能对应一个输出 | 能不能查（多值函数查表歧义）|

其中 **① 输入区间最关键**——它决定"直接查"还是"必须 range reduction"。
exp 能查得漂亮，就是因为有 $2^n·2^f$ 这个天然压缩。

---

## 三、逐激活函数结论

| 函数 | 能查吗 | 关键性质 | 结论 |
|---|---|---|---|
| **exp**（softmax）| ✅ 完美 | 有天然 range reduction（$2^n·2^f$）| 最佳案例，已实现 |
| **sigmoid** | ✅ 好 | $\sigma(-x)=1-\sigma(x)$，只查正半轴 | 表减半；饱和区曲率小可粗分 |
| **tanh** | ✅ 好 | 奇函数，只查正半轴 | 表减半；同样饱和 |
| **ReLU / LeakyReLU** | ❌ 不需要 | 就是 `max(0,x)` 或分段线性 | 比较指令更快，查表杀鸡用牛刀 |
| **GELU / SiLU / Swish** | ⚠️ 可查但小心 | 含 erf / sigmoid / tanh | 查 erf/tanh 表 + 一次乘法 |
| **1/x、rsqrt** | ✅ 好 | 有 range reduction（拆指数）| 牛顿迭代 + 查表混合更省 |
| **hard-sigmoid / hard-swish** | ❌ 不需要 | 本身就是分段线性 | 直接算，几个乘加搞定 |

---

## 四、判断清单（拿到一个函数按顺序问）

```
① 它是不是本来就是"比较 / 乘加 / 分段线性"？
   → 是：别查表（ReLU / hard-swish / LeakyReLU）
   → 否：继续
② 有没有天然 range reduction / 对称性 / 饱和性？
   → 指数→2的幂、奇偶性、饱和，都能压缩区间或砍半表
③ 输入区间能压到多小？        → 决定 h，决定需要几段
④ 曲率 f'' 在区间内变化大不大？→ 变化大→非均匀分段或加段
⑤ 精度要求多高？              → 反推段数和 Q
```

---

## 五、两个容易忽略的坑

**坑 1：饱和区可以"偷懒"**。sigmoid/tanh 在 |x|>5 后几乎贴平（斜率≈0），
这一段用平直线近似误差极小 → 饱和区粗分、陡峭区细分，即非均匀分段的现实意义。

**坑 2：陡 ≠ 难查**。`y=100x` 陡但直，查表零误差；抛物线顶点缓但弯，误差最大。
难查的是曲率（f''），不是斜率（f'）。这是"斜率 vs 曲率"最该记住的一点。

---

## 六、一句话总结

> 所有单值函数都能查表，判断"值不值得"看三点：**输入区间**（能不能 range reduction）、
> **曲率 f''**（决定误差，不是斜率）、**单值性**。ReLU 这类"比较/乘加就能算"的别查；
> exp/sigmoid/tanh 这类"有天然压缩 + 有对称性 + 会饱和"的才是查表主场。
